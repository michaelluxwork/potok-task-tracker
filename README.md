## Запуск на этом компьютере

Дважды откройте `START.cmd` или выполните из этой папки:

```powershell
.venv\Scripts\python.exe serve.py
```

Адрес: http://127.0.0.1:4350/. Если сервер уже запущен, просто откройте адрес; повторно занимать тот же порт не нужно. Остановка — Ctrl+C в окне сервера.

Создайте свой аккаунт через «Создать аккаунт». Для просмотра подготовленного проекта локальные логины и случайные пароли сохранены в `.state/demo-access.txt`: `lead` — руководитель, `maker` — исполнитель, `reader` — наблюдатель. Этот файл и сама база исключены из архива передачи и Git. Не используйте эти аккаунты в публичном сервисе. Доступ к реальным клиентским данным этим проектом не разрешён.

## Чистая установка из архива

Нужен Python 3.12+ и доступ к PyPI для первой установки. `START.cmd` создаёт окружение и ставит точные версии зависимостей. Ручной вариант:

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py migrate --noinput
.venv\Scripts\python.exe manage.py collectstatic --noinput
.venv\Scripts\python.exe serve.py
```

Пустая установка не создаёт аккаунт с общедоступным паролем. Для вымышленного проекта, если нужен локальный показ:

```powershell
.venv\Scripts\python.exe manage.py seed_demo
```

Команда запрещена в публичном режиме и не меняет уже существующие аккаунты. Повторный seed при наличии созданного файла доступа не дублирует проект. Чтобы войти в команду после регистрации, передайте руководителю точный логин; он добавит вас в «Участниках».

## Возможности

- Регистрация без email, вход и выход; пароль от 12 символов, серверные сессии и CSRF.
- Собственные доски и отдельный состав участников для каждой.
- Руководитель управляет задачами и участниками. Исполнитель создаёт задачи себе и меняет назначенные ему. Наблюдатель только читает. Последнего руководителя убрать нельзя.
- Задача: заголовок, описание, статус, приоритет, срок и ответственный. Редактирование, удаление с подтверждением, поиск, фильтр своих задач.
- Четыре колонки, drag & drop и форма смены статуса для клавиатуры/телефона. Результат подтверждает сервер; при ошибке карточка не изображает успех.
- Конфликт старой вкладки даёт 409; новые изменения сохраняются. При снятии исполнителя его задачи остаются без назначения.
- Адаптивный интерфейс, локальные SVG/стили, без внешней аналитики, шрифтов, email и AI-запросов.

Лимиты: 200 задач и 50 участников на доску, 20 досок на страницу, тело формы 32 KiB. Это локальный MVP для малой команды; публичная устойчивость к массовым регистрациям и подбору паролей не подтверждена.

## Данные и резервная копия

SQLite хранится в `.state/tracker.sqlite3`, секрет сессий — `.state/secret.key`. Папка содержит локальное состояние; не публикуйте её и не удаляйте для обновления программы. Копии:

```powershell
.venv\Scripts\python.exe manage.py backup_tracker
```

Команда делает согласованный online backup, проверяет `integrity_check` и оставляет пять последних копий в `.state/backups/`. Для восстановления остановите сервер, сохраните текущую БД отдельно, замените её проверенным backup и запустите `manage.py migrate --noinput`, затем сервер. Проверьте вход, доску и последнюю задачу. Не копируйте работающую SQLite-базу обычным файловым копированием.
